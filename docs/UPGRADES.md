The exported sample uses demonstration inputs of 10 orders/day, average order value 24 USD, PayPal share 0.4, failure probability 1 and exposure window 30 days, for an estimated USD 2,880. Its 1 December 2026 merchant target was entered during UI validation; it is demo data, not a PayPal announcement or an actual merchant notice.

No sandbox credentials were available, so no real sandbox transaction ID or live webhook delivery is claimed. The real sandbox path requires buyer approval plus a registered, publicly reachable signature-verification endpoint. Tests substitute tool responses and verify the webhook HTTP boundary. The agent demo persists into the web shop tables, not the separately hosted PHP database. The CLI gate compares synthetic fixtures, not two running shops. A hosted GitHub run and artifact upload require pushing the code; the action commands were tested locally, but no GitHub-hosted run was launched.
